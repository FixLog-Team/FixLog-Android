## 자세한 설명 (Full description · 4,000자 이내)

```
에러를 해결했는데, 다음에 같은 문제를 또 겪어본 적 있나요?

트러블슈팅 기록은 대부분 메모장, 슬랙, 개인 노트에 흩어져 남습니다. 막상 다시 필요할 땐 어디에 적어뒀는지, 왜 그렇게 해결했는지 찾기 어렵습니다. FixLog는 "기록은 했지만 활용되지 않는" 문제를 해결합니다.

가볍게 적기만 하면 AI가 문서로 정리해 주고, 필요할 때 의미 기반 검색으로 다시 꺼내 줍니다. 오류·원인·해결 과정·회고를 단순 메모가 아니라 쌓이는 지식 자산으로 만드세요.


■ 이런 분들께 좋아요
· 같은 에러를 반복해서 검색하는 개발자
· 트러블슈팅 과정을 블로그/노션에 정리하기 번거로운 분
· 팀의 문제 해결 경험을 자산으로 남기고 싶은 팀


■ 주요 기능

AI 자동 정리
난잡하게 적은 메모도 AI가 의미 단위로 요약하고 문서 형태로 구조화합니다. 원본은 항상 보존되고, AI 결과는 "제안"으로 제시되어 수락·거절을 직접 선택합니다. 문서에 어울리는 태그도 AI가 제안합니다.

의미 기반 AI 검색
키워드가 정확히 일치하지 않아도 "맥락"으로 찾습니다. 자연어로 질문하면 관련 문서와 근거가 된 문장을 함께 보여주고, 이어지는 대화로 더 깊이 파고들 수 있습니다.

블록 기반 에디터
제목·문단·리스트·코드 등 블록 단위로 자유롭게 작성합니다. 정리되지 않은 초안 그대로 저장해도 괜찮습니다 — 정리는 AI가 맡습니다.

폴더로 관리하는 문서 보관함
구글 드라이브처럼 폴더 구조로 문서를 정리하고, 이동·이름 변경·복제·즐겨찾기로 오래 쌓아도 흐트러지지 않게 관리합니다.

버전 기록 & 롤백
문서를 저장할 때마다 버전이 쌓입니다. 과거 내역을 미리 보고, 원하는 시점으로 언제든 되돌릴 수 있습니다.

휴지통
삭제한 문서·폴더는 휴지통에서 복원하거나 완전히 삭제할 수 있어 실수로 지워도 안전합니다.

PDF 내보내기
정리된 문서를 PDF로 다운로드해 공유하거나 보관하세요.


■ 팀을 위한 협업 (워크스페이스)
개인 보관함을 넘어, 팀 워크스페이스에서 문서와 폴더를 공유할 수 있습니다.
· 이메일로 구성원 초대, 역할(관리자/구성원) 부여
· 문서·폴더 단위 공유 권한과 다운로드 허용 설정
· 관리자 콘솔에서 구성원·권한·초대·감사 로그·통계 관리
· 보안 정책(공유/다운로드 허용, 보관 기간) 설정


■ 작동 방식
1) 트러블슈팅 메모를 자유롭게 작성
2) 저장하면 문서로 보관되고 검색 인덱스가 만들어짐
3) "요약" 버튼으로 AI가 문서를 깔끔하게 정리
4) 나중에 AI 검색으로 과거의 해결책을 다시 발견


구글 계정으로 간편하게 시작하세요. 당신이 해결한 모든 문제가, 다음 문제를 더 빨리 푸는 자산이 됩니다.

FixLog — 해결한 문제는 사라지지 않습니다.
```

## 참고 (붙여넣기 전 확인)

- **언어**: 기본 언어를 한국어(ko-KR)로 설정 후 위 문구를 입력하세요.
- **그래픽 자산**:
  - 앱 아이콘(512×512): `store/play_store_icon_512.png`
  - 피처 그래픽(1024×500): `store/feature_graphic_1024x500.png`
  - 스크린샷(필수, 최소 2장): 앱 실제 화면 캡처 필요 (휴대폰 스크린샷 16:9 또는 9:16, 320~3840px)
- **기능 표현 주의**: 협업/관리자/PDF 등 일부 기능은 서버 연동 상태에 따라 실제 동작을 확인한 뒤 문구를 조정하세요. 스토어 설명과 실제 앱 동작이 다르면 심사에서 문제가 될 수 있습니다.
