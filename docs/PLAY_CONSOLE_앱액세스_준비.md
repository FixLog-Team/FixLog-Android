# Play Console 앱 액세스(App access) 준비 가이드

> 목적: 앱 출시 시 **앱 콘텐츠 → 앱 액세스 권한**에서 "앱에 제한된 부분이 있나요?"에 **예(일부/전체 기능 제한됨)** 로 답하고,
> 심사자(Google 리뷰어)가 로그인해 제한된 기능을 확인할 수 있도록 **접근 안내 + 데모 자격증명**을 등록하기 위한 준비 문서.
> 대상 앱: FixLog Android (`kr.co.fixlog`) · 로그인 방식: Google OAuth (서버 브로커드)

---

## 0. 왜 "예(제한됨)" 인가
FixLog는 **로그인하지 않으면 문서/검색/설정 등 핵심 기능을 사용할 수 없다.** 따라서 앱 액세스 페이지에서
"모든 기능을 특별한 액세스 없이 사용 가능"이 아니라 **"일부 또는 모든 기능이 제한됨"** 을 선택하고,
각 제한 흐름에 대해 심사자용 안내를 제공해야 한다.

---

## 1. 앱 액세스 페이지에 등록할 항목

Play Console → **앱 콘텐츠 → 앱 액세스 권한 → "일부 또는 모든 기능이 제한됨"** 선택 → **안내 추가**.

제한 흐름별로 아래 3가지를 등록한다.

| 필드 | 내용(예시) |
|---|---|
| 이름(레이블) | `로그인 필요 (Google 계정)` |
| 사용자 이름/이메일 | `리뷰용 데모 Google 계정 이메일` |
| 비밀번호 | `데모 계정 비밀번호` |
| 기타 안내(단계별) | 아래 §3 "접근 안내 문구" 붙여넣기 |

> 여러 제한 흐름(예: 협업 워크스페이스, 관리자 콘솔)이 있으면 각각 별도 항목으로 추가한다.
> 현재 필수는 **로그인 1개**이며, 협업/관리자는 선택.

---

## 2. 데모 계정 준비 체크리스트 (가장 중요)

Google OAuth 로그인이므로 **리뷰어가 실제로 로그인 가능한 Google 계정**을 제공해야 한다.

- [ ] **리뷰 전용 Google 계정 신규 생성** (개인 실계정 사용 금지)
- [ ] **2단계 인증(2FA)·OTP 비활성화** — 리뷰어는 동적 코드를 받을 수 없음 (정적 자격증명만 가능)
- [ ] **비밀번호 만료/주기적 변경 없음**, 휴면 방지(출시~심사 기간 상시 유효)
- [ ] **지역 제한 없음** — 리뷰 서버는 해외에서 접속하므로 "새 기기/위치 확인"으로 막히지 않도록 사전 로그인 1~2회 해 두기
- [ ] **복구 이메일/전화 설정**은 해두되, 로그인 시 추가 확인이 뜨지 않는 상태로 유지
- [ ] 데모 계정에 **샘플 문서·폴더 몇 개 미리 생성** (빈 화면만 보이면 기능 확인 불가)
- [ ] (협업 기능 노출 시) 데모 계정을 **데모 워크스페이스에 미리 소속**시키거나 초대 링크/토큰 안내 포함

### 리스크 & 완화
- Google 심사 환경의 **자동 로그인 로봇 감지**로 로그인이 막힐 수 있음 →
  - 깨끗한 신규 계정 + 2FA 해제 + 사전 정상 로그인 이력 확보로 완화
  - 안내 문구에 "지역/기기 확인 화면이 뜨면 승인 필요" 명시
- (대안) 심사 전용 **이메일+비밀번호 로그인 경로**를 서버 시크릿으로 게이트해 임시 제공하는 방법도 있으나,
  운영 노출 위험이 있어 **권장하지 않음**. 기본은 데모 Google 계정.

## 3. 접근 안내 문구 (복사용 템플릿)

> Play Console "기타 안내" 칸에 붙여넣기. 국문/영문 병기 권장.

```
[한국어]
FixLog는 Google 계정 로그인 후 모든 기능을 사용할 수 있습니다.

1. 앱을 실행합니다.
2. "Google 계정으로 로그인" 버튼을 누릅니다.
3. 아래 데모 계정으로 로그인합니다.
   - 이메일: <데모 계정 이메일>
   - 비밀번호: <데모 계정 비밀번호>
4. 로그인 후 하단 탭(문서 / 검색 / 설정)에서 기능을 확인할 수 있습니다.
   - 문서: 폴더/문서 목록 및 편집
   - 검색: AI 검색(대화형)
   - 설정: 워크스페이스/로그아웃
※ 로그인 중 "새 기기/위치 확인" 화면이 나오면 승인해 주세요.

[English]
FixLog requires signing in with a Google account to use its features.

1. Launch the app.
2. Tap "Sign in with Google".
3. Sign in with the demo account below.
   - Email: <demo email>
   - Password: <demo password>
4. After signing in, use the bottom tabs (Documents / Search / Settings).
Note: If a "new device/location verification" screen appears, please approve it.
```

## 4. 함께 완료해야 하는 연관 항목 (계정 있는 앱 필수)

앱 액세스 외에도, 계정/로그인이 있는 앱은 아래 **앱 콘텐츠** 항목을 함께 채워야 심사를 통과한다.

### 4.1 데이터 보안 (Data safety)
- [ ] 수집 데이터 신고: **이메일, 이름(프로필), 인증 토큰(앱 기능)**, 사용자가 작성한 문서 콘텐츠
- [ ] 목적: 앱 기능(계정/인증), (해당 시) 분석
- [ ] **전송 중 암호화(HTTPS)** = 예
- [ ] 데이터 삭제 요청 가능 = 예 (아래 4.2와 연결)
- [ ] 제3자 공유 여부 정확히 신고

### 4.2 계정 삭제 (Account deletion)
- [ ] 계정이 있는 앱은 **계정·데이터 삭제 경로 제공이 필수**
- [ ] 웹 URL 준비: 예) `https://fixlog.art/account/delete` (로그인 없이도 삭제 요청 접수 가능한 안내 페이지)
- [ ] 가능하면 **인앱 삭제 메뉴**(설정 화면)도 함께 제공
- [ ] Play Console → 앱 콘텐츠 → 데이터 보안의 "계정 삭제" URL 등록

### 4.3 Google OAuth 동의 화면 (Google Cloud Console, Play와 별개)
- [ ] OAuth 동의 화면을 **게시됨(Production)** 상태로 전환 → "미확인 앱" 경고 방지
- [ ] 사용 범위: 이메일/프로필(비민감)만 사용 시 별도 보안 심사 불필요
- [ ] 앱 로고/개인정보처리방침 URL/홈페이지 URL 등록

### 4.4 개인정보처리방침 (Privacy policy)
- [ ] 공개 URL 준비 후 Play Console 스토어 등록정보 + 앱 콘텐츠에 등록
- [ ] 수집 항목/목적/보관/삭제/문의처 포함

---

## 5. 최종 제출 전 체크리스트

- [ ] 앱 액세스: "일부/전체 제한됨" 선택 + 로그인 안내 + 데모 계정 등록
- [ ] 데모 Google 계정 실제 로그인 성공 확인(2FA off, 지역 확인 통과)
- [ ] 데모 계정에 샘플 데이터 존재
- [ ] 데이터 보안 설문 완료
- [ ] 계정 삭제 URL 등록
- [ ] 개인정보처리방침 URL 등록
- [ ] OAuth 동의 화면 게시 상태

---

## 참고
- Play Console 앱 액세스: 앱 콘텐츠 → 앱 액세스 권한
- 계정 삭제 정책: Google Play "사용자 데이터" 정책(계정 삭제 요구사항)
- OAuth 네이티브 앱 권장 방식: 별도 문서/`A. Custom Tabs 전환` 참고 (RFC 8252)
